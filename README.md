# أصايل لاين | ASAYEL LINE

واجهة متجر عبايات عربية، مستلهمة من تنظيم متجر Carol، بهوية أصايل لاين الخاصة. تصميم متجاوب مع الجوال، دون مكتبات أو خطوة بناء.

## الموجود في هذه النسخة

- واجهة عربية باتجاه RTL، وخط Alexandria محلي.
- صور تصورية مولدة خصيصًا للمعاينة. ليست صور منتجات حقيقية.
- تصنيف وبحث وترتيب المنتجات بالسعر.
- تفاصيل المنتج واختيار المقاس.
- حقيبة مشتريات وتعديل الكميات والمفضلة، محفوظة على جهاز الزائرة.
- دليل مقاسات، ونصائح عناية، ومعلومات وأسئلة شائعة.
- ملف GitHub Actions جاهز للنشر على GitHub Pages.

## نشر نسخة المعاينة على GitHub Pages فقط

1. ارفعي/ارفع الملفات إلى الفرع `main` في `TAALAQ/ASAYEL_`، مع مجلد `assets` ومجلد `.github`.
2. من المستودع: **Settings → Pages → Source → GitHub Actions**.
3. من تبويب **Actions**، شغّل سير العمل أو انتظر تشغيله بعد رفع الملفات.
4. رابط الموقع المتوقع بعد نجاح النشر: https://taalaq.github.io/ASAYEL_/

اسم المستودع يحتوي على شرطة سفلية في نهايته؛ روابط الملفات كلها نسبية وتعمل على مسار المستودع.

## تعديل المحتوى

- بيانات المنتجات والمقاسات والأسعار: `store-config.js`.
- النصوص والأقسام: `index.html`.
- الألوان والتنسيق: `styles.css`.
- صور الواجهة: `assets/hero.png` و`assets/catalog.png`.
- رمز القوس مستلهم من مرجع الشعار المرسل. ملف SVG منفصل، والاسم مكتوب كنص قابل للتحرير.

## قبل بدء البيع

GitHub Pages لا يسمح باستخدام استضافته المجانية لتشغيل متجر تجاري أو تسهيل معاملات البيع. يُحفظ الكود في GitHub، لكن نسخة المتجر الفعلية تحتاج استضافة مناسبة للتجارة الإلكترونية. المرجع: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits


هذه **واجهة معاينة** وليست نظام متجر جاهزًا لتحصيل المدفوعات. المنتجات والأسعار تصورية. لا يوجد مخزون أو تسجيل طلبات أو بوابة دفع أو إدارة عملاء. لا تغيّر `preview` إلى `false` قبل تجهيز النظام الفعلي.

يلزم إضافة صور المنتجات الحقيقية، وصف الخامات والقياسات والأسعار والمخزون، بيانات التواصل الرسمية، وسياسات الشحن والاستبدال والخصوصية. يجب ربط واجهة المتجر بنظام تجارة إلكترونية وبوابة دفع معتمدة؛ GitHub Pages يستضيف ملفات ثابتة ولا يعالج الطلبات بنفسه. حقل `checkoutUrl` مخصص لرابط خدمة دفع خارجية مجهزة، ولا يرسل محتويات السلة تلقائيًا؛ يلزم تكامل فعلي عند الإطلاق.

لا يحتوي المتجر على شهادات عملاء أو عروض أو مواعيد شحن مختلقة. البيانات المؤقتة المرسلة لم تُنشر كقنوات تواصل فعالة.
